# @licenroute/connect-express — developer preview

> **Status: developer preview, demo mode only. Not published to npm.** In this repository the SDK talks to the local
> LicenRoute simulator, with synthetic credentials. The hosted LicenRoute service (Central) is not available and is not part
> of this repository. Nothing here charges money or processes real payments.

Express 4/5 (and Connect-compatible) middleware. Before your route runs, it asks a LicenRoute decision endpoint what to do
and applies the answer: continue, `402` (licence required), `403` (licence revoked or invented), `429` (over quota,
with `Retry-After`) or `503` (the decision cannot be made safely).

You normally do not write this by hand: `licenroute init` proposes the exact diff and writes it only after you type the
challenge in your own terminal. See the [tutorial](../../docs/tutorial-express.md).

## What the integration looks like

```js
import express from "express";
import { licenroute } from "@licenroute/connect-express";

const app = express();
app.use(licenroute({
  apiKey: process.env.LICENROUTE_API_KEY,      // demo: generated by `licenroute dev`, valid only against the simulator
  siteId: process.env.LICENROUTE_SITE_ID,
  endpoint: process.env.LICENROUTE_ENDPOINT,   // demo: http://127.0.0.1:<port> (loopback only)
  allowInsecureEndpoint: true,              // demo only: plain HTTP to loopback
  licensedPaths: [{ path: "/api/informes/**", methods: ["GET", "HEAD"] }],
  withoutPolicy: "deny",
}));
```

## Key behaviour

- **Methods (0.7.0).** `{ path, methods }` requires a licence **only** for those methods. A `POST` with your own
  authentication under the same prefix is untouched (fix for F-D4-1). A plain string pattern still means every method.
  `GET` does not imply `HEAD`: declare both (the CLI always does). `OPTIONS` is never licensable.
- **Fail closed on paid routes.** If no trusted policy covers a declared paid route, the SDK answers
  `503 licensed_route_not_covered` and never runs your handler; `protection.ready()` stays `false`.
- **Licences** arrive as `Authorization: Bearer bgat_…` or `BotGate-Access-Token: bgat_…` and are stripped before your
  app sees the request.
- **What is sent to the decision endpoint:** method, path without query string, client IP, User-Agent and boolean
  signals. Never cookies, `Authorization`, bodies or parameters.
- **Only routes behind the middleware are protected.** Routes mounted before `app.use(licenroute(...))` are not.

## Not ready for production

The option surface also covers features of the hosted service (policy sync, attestations, identity pseudonyms, circuit
breaker). They are exercised by the unit tests in `test/`, but there is no public service to point them at, and this
preview has not been reviewed for production traffic or real credentials. Use synthetic credentials only.

## Development

```bash
npm test -w @licenroute/connect-express        # unit tests (Express 4 and 5)
npm run build -w @licenroute/connect-express   # dist/ with the internal contracts bundled; runtime dependency: typebox
```
